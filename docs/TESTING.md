O processo é encerrado e o usuário temporário é removido. Recibos sem PII permanecem até a expiração/limpeza normal.

Teste real Microsoft depende de configuração externa e é separado: siga `MICROSOFT_GRAPH_EMAIL.md`, usando `.env.graph.local` privado e `npm run email:test -- --send`. Não rode com endereços de candidatos reais. Resposta 202 indica aceite, não entrega final; confira recebimento e escopo da caixa.

Para verificar somente o carregamento do script, execute `npm run email:test` sem `--send`: deve exibir a orientação de uso e encerrar com código 1, sem conectar à Microsoft. O script usa uma função assíncrona para ser compatível com o formato CommonJS emitido pelo `tsx` neste projeto.
