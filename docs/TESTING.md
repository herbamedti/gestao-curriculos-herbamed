## E-mails Microsoft Graph (05/10/2026)

`npm run check` cobre o adaptador Graph com respostas simuladas (token/renovação, concorrência, permissões, limites e falhas sem PII), schema/configuração de deploy e o hook assinado: assinatura inválida/expirada, tamanho, payload, domínio dos links, retry, falha e troca segura nos dois endereços. `npm run test:db` cobre RPCs exclusivas de serviço, RLS, escrita direta negada, leases e recibos sem PII. `npm run test:e2e:email` inicia uma aplicação temporária na porta 3001 com Mailpit/Supabase locais e dados fictícios; verifica POST assinado, retry sem duplicar, GET sem consumir token, confirmação por clique, recuperação e código da Conta. O processo é encerrado e o usuário temporário é removido. Recibos sem PII permanecem até a expiração/limpeza normal.

Teste real Microsoft depende de configuração externa e é separado: siga `MICROSOFT_GRAPH_EMAIL.md`, usando `.env.graph.local` privado e `npm run email:test -- --send`. Não rode com endereços de candidatos reais. Resposta 202 indica aceite, não entrega final; confira recebimento e escopo da caixa.

Para verificar somente o carregamento do script, execute `npm run email:test` sem `--send`: deve exibir a orientação de uso e encerrar com código 1, sem conectar à Microsoft. O script usa uma função assíncrona para ser compatível com o formato CommonJS emitido pelo `tsx` neste projeto.
